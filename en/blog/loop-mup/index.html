Loop-μP: Residual Scaling and Hyperparameter Transfer in Looped Transformers

Looping is not extra depth: scale each residual branch by 1/N, and the learning rate transfers across loop counts

A looped Transformer runs the same stack of L layers N times. It stores the parameters of only L layers but executes N×L of them. Prior work finds that looping helps models carry out multi-step reasoning, and in language modeling downstream accuracy rises with the loop count N, most strongly on reasoning tasks. Increasing N is therefore a natural way to scale a looped model.

As N grows, however, training becomes unstable and the best learning rate moves, so it has to be searched again for every N. Ouro, for example, reduced the loop count after observing loss spikes, and adopted a conservative learning rate because its compute budget did not allow a learning-rate sweep.

For width and depth, this problem already has an answer. μP and Depth-μP choose a parameterization under which the best hyperparameters stay put as the model gets wider or deeper, so they can be tuned on a small model and reused on a large one. We ask: can the loop count N do the same?

Our answer is Loop-μP: on top of the existing depth scaling, multiply each residual branch by 1/N and keep the learning rate independent of N. In our language-modeling experiments, the base learning rate tuned on the smallest model stays best for loop counts up to 8 and executed depths up to 384 layers. The key point is that loops cannot simply be treated as extra depth: all loops share the same weights, so the increments they write into the residual stream add along the same direction.

Looping is not extra depth

Each branch of a residual network updates the residual stream as x ← x + c·f(x), where c is the branch multiplier. A deeper network adds more increments, so depthwise parameterizations shrink c as the depth L grows. Depth-μP uses c ∝ L−1/2 and CompleteP uses c ∝ L−1, and both transfer the learning rate across depths.

A model of L layers looped N times executes N×L layers. Treating the loops as extra depth seems natural, which would multiply the branch by another N−1/2. The catch is weight sharing. At initialization, L independent layers write increments in nearly unrelated directions, so like a random walk their sum grows only as √L. When one block is looped N times, every loop uses the same weights, the increments are positively correlated, and their sum grows linearly in N.

Real Transformers behave the same way. We loop a 12-layer pre-norm Transformer stack N times and compare it with untied models that chain mL independent 12-layer stacks (depth multiplier mL = L/12), measuring the residual-stream norm at initialization. Without scaling, the looped norm grows linearly in N, while the untied norm grows only as √mL. For the untied model, mL−1/2 already keeps the norm of order one. For the looped model, N−1/2 is not enough and only N−1 works. N−3/2 also bounds the norm, but it drives the looped model toward the identity map.

The cosine similarity between increments explains the difference: the increments of 64 independent stacks are nearly orthogonal, whereas the 64 increments of a looped stack are all positively correlated, with a mean cosine of about 0.85.

Why exactly 1/N

The measurements in the previous section raise two natural questions. First, if the goal were merely to keep the initialized residual stream bounded, why not decay even faster, say as N−3/2? Second—and more importantly for training—since the same weights are reused across all N loops and receive N gradient contributions on the backward pass, does the learning rate also need to be scaled with N?

This section works out both answers. Write the residual branch multiplier as cN = aN−αN (where a is a constant independent of N), and write N−γN for how the step size of a single weight update scales with N (for Adam, which normalizes gradient magnitudes automatically, this is directly how the learning rate scales with N). We want to find the pair of exponents (αN, γN).

Before diving into matrix algebra, we can summarize the entire argument in three lines. For a single learning rate to work across all loop counts N, the network must neither blow up nor stall as N grows:

  • Step 1 (Stable forward pass at initialization): Each loop writes an increment of size cN into the residual stream. Because all loops share weights, the N increments add along the same direction, giving a total increment of size N·cN ∝ N1−αN. Keeping initialization from blowing up requires αN ≥ 1.
  • Step 2 (Bounded feature update in a single loop): One optimization step changes the weights by scale N−γN, so the branch output in a single loop changes by N−γN. Keeping feature updates from blowing up with N requires γN ≥ 0.
  • Step 3 (Order-one change in the final output): The updated weights are reused in all N loops. In each loop, the residual branch (multiplied by cN) nudges the final output in the loss-reducing direction by cN·N−γN; summed over N aligned loops, the total output change is N·cN·N−γN ∝ N1−αN−γN. If this change grew with N, the optimal learning rate would have to shrink with N; if it vanished with N, training would stall unless the learning rate grew with N. Only when it stays of order one—requiring αN + γN = 1—does one learning rate suit every N.

Putting the three conditions together, Steps 2 and 3 give αN = 1 − γN ≤ 1 (an upper bound from training), while Step 1 gives αN ≥ 1 (a lower bound from the forward pass). The two bounds meet head-on, leaving the unique solution (αN, γN) = (1, 0).

The figure below draws this ledger. Each line is a bar made of pieces, and the dashed line marks its length at N = 1. Set cN = 1/N, keep the learning rate fixed, and change N: there are more pieces, each proportionally narrower, and all three bars stay on the dashed line. With any other branch multiplier or learning-rate scaling, at least one bar grows or shrinks with N.

The ledger takes three facts for granted: why the increments of a shared block add along one direction, why the features change by as much as the weights do, and why the N loops push the output with the same sign. We now explain each in the simplest possible model, with one figure per step; the full algebra sits in fold-out blocks that can be skipped without losing the thread.

A minimal model and μP initialization. Following Depth-μP, we consider a looped residual network of width n with a single trainable hidden matrix W ∈ ℝn×n applied N times, while the input vector U ∈ ℝn and readout vector V ∈ ℝn stay fixed. To compute every term in closed form, we set the scalar input to 1 and use the identity activation (the paper also subtracts the coordinate mean of each residual branch, which we omit here):

Input & readout𝒙0=𝑼,f=𝑽⊤𝒙N=⟨𝑽,𝒙N⟩
Loop r𝒉r=𝑾𝒙r−1,𝒙r=𝒙r−1+cN𝒉r(r=1,…,N),cN=aN−αN

Here hr is the output of the branch matrix W in loop r, xr is the residual stream after loop r, and the scalar output f is the standard inner product ⟨V, xN⟩ = ∑iVixiN.

The initialization follows μP, which keeps each coordinate of a hidden vector of order one (written Θ(1)): each coordinate of U is about 1, each entry of W about 1/√n, and each coordinate of V about 1/n. We measure vector length by the root-mean-square (RMS) norm ‖z‖rms = √(⟨z, z⟩/n), the typical magnitude of a single coordinate.

Throughout, we take the large-width limit n → ∞ first, and then ask how each quantity scales as the loop count N grows.

Full derivation: what each 1/n in the μP initialization does+

In a width-n network, we want each coordinate of an activation vector to stay of order one. Under μP initialization, each factor of 1/n has a specific job:

  • Input vector U: coordinates are independent 𝒩(0, 1), so each coordinate is about 1 and ‖U‖rms ≈ 1 (with inner product ⟨U, U⟩ ≈ n).
  • Hidden matrix W: entries are independent 𝒩(0, 1/n). Why variance 1/n? Because each coordinate (WU)i = ∑jWijUj sums n independent terms of variance 1/n, giving variance 1. Thus multiplying by W preserves the RMS length of a vector: ‖WU‖rms ≈ 1.
  • Readout vector V: coordinates are independent 𝒩(0, 1/n2), so each coordinate has size about 1/n (and ⟨V, V⟩ ≈ 1/n). The readout is this small because f = ∑iVixiN sums n coordinates: at initialization V is unrelated to xN and the terms cancel to f ≈ 0; once training aligns the change of xN with V, adding n aligned terms of size 1/n produces an order-one change in the output f.

A key tool: at large width, each multiplication by W turns a vector to a new orthogonal direction. In the plane, multiplying a vector by a random matrix can send it in any direction and stretch or shrink it at will. At large width the picture is completely different: WU almost always has the same length as U and is almost always orthogonal to it. The figure below draws 200 samples at each width: at n = 2 the samples scatter over the whole half-disc, and as n grows they collapse onto 90° and a length ratio of 1, with a spread that shrinks roughly as 1/√n. Multiplying by W once more gives W2U, again nearly orthogonal to both earlier vectors.

Our derivation only needs three direct consequences of this fact:

  • Distinct powers are pairwise orthogonal: U, WU, W2U, … are pairwise orthogonal with RMS length tending to 1.
  • Backward multiplications by W⊤ behave the same way: V, W⊤V, (W⊤)2V, … are also pairwise orthogonal, each with self-inner-product ⟨V, V⟩ ≈ 1/n.
  • Products of distinct independent matrices are pairwise orthogonal: if layers have independent weights W1, W2, …, then W1U and W2U are orthogonal as well, each with RMS length tending to 1.
Full derivation: why one multiplication by W gives an orthogonal direction+

The previous fold-out explains why the length is preserved: each coordinate (WU)i sums n independent terms of variance 1/n. What about the direction? Look at the inner product ⟨U, WU⟩ = ∑i,jUiWijUj: it sums n2 uncorrelated terms of mean 0 and standard deviation 1/√n, which cancel down to order √n—negligible compared with the squared length ⟨U, U⟩ ≈ n (their cosine is about 1/√n → 0). In high dimensions, each multiplication by the random matrix W rotates the vector into a fresh direction orthogonal to the previous ones.

The rigorous random-matrix proof appears in Tensor Programs and the paper’s appendix.

Step 1 (Stable forward pass): shared weights make same-order terms add in length, requiring αN ≥ 1. Each loop multiplies the residual stream by (I + cNW), so after N loops xN = (I + cNW)NU. When we expand the product, each loop either follows the identity trunk I or takes the residual branch cNW. There are 2N paths in total, and each path is one term of the expansion. The figure below lists all of them; click a path to see which term it gives.

Compare two layers (N = 2) with independent versus shared weights. There are two ways to take the residual branch once (the first-order terms, m = 1): take the branch in loop 1 and the trunk in loop 2, or vice versa. With independent weights (W1 and W2), the two paths produce two orthogonal vectors cW1U and cW2U, whose combined length by Pythagoras is √2·c. With a shared weight W, both paths produce the exact same vector cWU, which adds in length to 2c. Across N loops, there are C(N, m) ways to choose m loops to take the branch. Under shared weights every one of them yields the same vector cNmWmU, with combined length C(N, m)·cNm; under independent weights they yield C(N, m) mutually orthogonal vectors, with combined length only √C(N, m)·cNm.

This also explains Figure 3 algebraically: the increment cNWxr−1 written in loop r always starts with the same vector cNWU and has positive coefficients on all higher powers, so increments from different loops are positively correlated.

The stability condition for the forward pass can be read off from the first-order term (m = 1). Being a single term of the expansion, it must stay bounded: that is a necessary condition. It is also sufficient, because the higher orders are controlled by the first one (C(N, m) is at most Nm/m!), so the total length is squeezed between two functions of the first-order term:

  • Independent weights (depth): the first-order term has length √N·cN, and the squares of all orders sum to (1 + cN2)N, which lies between 1 + NcN2 and eNcN2. The residual stream is therefore bounded if and only if √N·cN is, that is, if the branch multiplier shrinks at least as fast as N−1/2—which is why Depth-μP can use L−1/2.
  • Shared weights (loops): the first-order term has length N·cN = aN1−αN, and the total length lies between N·cN and eN·cN. If we still used cN = N−1/2 (say cN = 1/4 at N = 16), the first-order term would have length 1 for independent layers but 4 for shared loops, and including higher orders pushes the total length to about 15 (Figure 7). The residual stream is therefore bounded if and only if N·cN is, that is, αN ≥ 1; the total length is then at most ea for any N.

If αN > 1 (such as N−3/2), then N·cN → 0, every residual term vanishes as N grows, and xN → U, collapsing the looped network to the identity map. The forward pass alone does not blow up, but the training analysis below rules it out.

Now compute the total length of xN. Because distinct powers WmU are orthogonal, the squared length of xN is the sum of the squared lengths of each order m. Shared and independent weights differ only in how the C(N, m) terms within the same order m combine: with shared weights, C(N, m) identical vectors add in length (squaring to C(N, m)2); with independent weights, C(N, m) orthogonal vectors add in quadrature (squaring to C(N, m)):

Shared‖𝒙N‖rms2→∑m=0N(Nm)2cN2m=1+(NcN)2⏟m = 1: add in length+⋯

  • Independent weights: the first-order term has squared length NcN2, and all orders sum to (1 + cN2)N. This is at least the first two terms of the expansion, 1 + NcN2, and at most eNcN2, so it is bounded if and only if NcN2 is.
  • Shared weights: for the lower bound, the squared total is at least the squared first-order term (NcN)2. For the upper bound, C(N, m) ≤ Nm/m! bounds the length of order m by (NcN)m/m!, so the lengths of all orders sum to at most eNcN, and so does the total length (the root of the sum of their squares). When αN ≥ 1, NcN ≤ a and the total length is at most ea.

Step 2 (One update step and feature change): why training stability requires γN ≥ 0. Now consider one gradient step. Let ℓ′ = ∂ℓ/∂f be the derivative of the loss with respect to the scalar output f, and let br = ∂f/∂xr be the gradient of f with respect to the residual stream after loop r. Because N − r loops remain between xr and xN, backpropagation multiplies the readout vector V by (I + cNW⊤)N−r; its zeroth-order term is V, so each coordinate of br has size about 1/n.

Because the same W is used in all N loops, the chain rule sums the outer-product gradients from all N loops: loop r takes input xr−1 (entries ∼ 1) and receives backward signal cNℓ′br (entries ∼ cN/n), contributing cNℓ′br(xr−1)⊤ to G. This is the same as backpropagation through time (BPTT) in a recurrent network, where the gradients of the tied weights are summed over time steps:

Gradient𝑮=∂ℓ∂𝑾=ℓ′cN∑r=1N𝒃r(𝒙r−1)⊤,𝒃r=∂f∂𝒙r=(𝑰+cN𝑾⊤)N−r𝑽

Could these N terms cancel one another? They cannot. Every loop input xr−1 starts with the same U, and every backward signal br starts with the same V, so the gradient contributions of any two loops are positively correlated. The figure below computes their pairwise cosine similarity in the model above: all of them are positive, and the sum of the N terms is close to N times as long as a single term, rather than the √N times of mutually orthogonal terms. This is the same mechanism as the N aligned increments of Step 1: each term carries one factor of the branch multiplier cN, N aligned terms add up, and the gradient has scale N·cN.

One update moves the weights along the negative gradient by an amount of scale N−γN, the step size defined at the start of this section. Every term of the gradient is the outer product of a backward signal and an input that starts with U; in other words, the gradient is aligned with the input U, so the first-loop feature h1 = WU changes by Δh1 = ΔWU, of scale N−γN. Keeping the feature change bounded as N grows therefore requires γN ≥ 0. When the forward pass is stable (αN ≥ 1), the changes in all subsequent loops have the same scale.

Full derivation: one update step and the first-loop feature change+

To cover both Adam and SGD with a single exponent γN, we parameterize how the weight update ΔW scales with N by averaging the N outer products (dividing by N) and multiplying by the step-size factor N−γN (in the paper’s Tensor Programs notation, the gradient is first rescaled by nNαN−1 so its entries are Θ(1), and then multiplied by learning rate ηn−1N−γN, which yields the exact same ΔW):

One stepΔ𝑾=−ηaℓ′N−γN·1N∑s=1N𝒃s(𝒙s−1)⊤
First loopΔ𝒉1=Δ𝑾𝑼=−ηaℓ′N−γN·1N∑s=1N⟨𝒙s−1,𝑼⟩⏟≈ n𝒃s⏟entries ∼ 1/n⟹‖Δ𝒉1‖rms∝N−γN

Notice how γN connects to the actual optimizer learning rate: since each outer product bs(xs−1)⊤ has entries of size 1/n, their average over s also has entries of size 1/n, so each entry of ΔW has size N−γN/n. Because Adam normalizes the gradient entrywise by its root-mean-square magnitude, the overall scale of G cancels out and the step size is set directly by the learning rate—so for Adam, N−γN is simply how the learning rate scales with N.

Now look at the second line of the equation above—how much the first-loop feature h1 = WU changes after one step:

  • The input x0 = U to the first loop is fixed, so the feature change is Δh1 = ΔWU exactly.
  • Multiplying each outer product bs(xs−1)⊤ on the right by U turns the matrix-vector product into the scalar inner product ⟨xs−1, U⟩ times the vector bs.
  • Why is ⟨xs−1, U⟩ ≈ n? Because every loop input xs−1 = U + (s − 1)cNWU + ⋯ starts with U, while all higher-order terms are orthogonal to U, reducing the inner product to ⟨U, U⟩ ≈ n. This factor of n cancels the 1/n entry size of bs, bringing each coordinate back to Θ(1)—the core mechanism of μP: because ΔW is built from outer products of the training inputs, it aligns with U and amplifies 1/n-sized weight updates by a factor of n.
  • At the same time, all bs share the zeroth-order term V and are positively correlated, so averaging over s does not cancel them out. Thus ‖Δh1‖rms has scale N−γN.

Step 3 (Change in the final output): one update pushes the output along the same direction in all N loops, requiring αN + γN = 1. Finally, we compute how much one step changes the scalar output f. Once W is updated by ΔW, that same ΔW acts in all N loops. In loop r, the residual branch writes an extra cNΔWxr−1 into xr; by the definition of br = ∂f/∂xr, that extra increment changes the final output f (to first order in ΔW) by its inner product with br, namely Δfr = cNbr⊤ΔWxr−1.

Δfr is exactly the inner product between the update ΔW and the contribution of loop r to the gradient of f with respect to W. The update points along the negative gradient of the loss, and the figure above shows that every term of the gradient is aligned with the r-th one, so every Δfr has the sign of −ℓ′: all N loops push the output in the direction that lowers the loss, and nothing cancels. Each loop contributes an amount proportional to the branch multiplier cN times the update step size N−γN, and summing N aligned contributions multiplies by N:

Total Δf|Δf|=∑r=1N|Δfr|∝N⏟N aligned loops·cN⏟branch N^(−α_N)·N−γN⏟update step=aN1−αN−γN

For one optimization step to change the output by an order-one amount that neither blows up nor vanishes with N, the exponent must vanish: 1 − αN − γN = 0, or αN + γN = 1.

Full derivation: the two inner products in the output change+

Substitute ΔW into Δfr. When br⊤ on the left and xr−1 on the right sandwich the outer product bs(xs−1)⊤, the matrix product factors neatly into the product of two scalar inner products: br⊤bs(xs−1)⊤xr−1 = ⟨br, bs⟩⟨xr−1, xs−1⟩:

By loopΔf≈∑r=1NΔfr,Δfr=cN𝒃r⊤Δ𝑾𝒙r−1
Plug in ΔWΔfr=−ηaℓ′cNN−γN·1N∑s=1N⟨𝒃r,𝒃s⟩⏟∼ 1/n, > 0⟨𝒙r−1,𝒙s−1⟩⏟∼ n, > 0

All that remains is to check the sign and magnitude of the forward inner product ⟨xr−1, xs−1⟩ and the backward inner product ⟨br, bs⟩ between any two loops r and s.

The reason both are positive is immediate: every loop input xr−1 starts with U, and every backward signal br starts with V. Because different powers of W are orthogonal, only terms of the same order m contribute to each inner product, and every order enters with a nonnegative coefficient:

Inputs1n⟨𝒙r−1,𝒙s−1⟩→1⏟m = 0 (from U)+∑m≥1(r−1m)(s−1m)cN2m∈[1,ea2]
Backwardn⟨𝒃r,𝒃s⟩→1⏟m = 0 (from V)+∑m≥1(N−rm)(N−sm)cN2m∈[1,ea2]

In the two rows above, the m = 0 leading term is 1 (coming from ⟨U, U⟩/n → 1 and n⟨V, V⟩ → 1), and all higher-order terms are nonnegative; when the forward pass is stable (NcN ≤ a), each sum lies in [1, ea2]. Multiplying the two inner products cancels the factors of 1/n and n, so ⟨br, bs⟩⟨xr−1, xs−1⟩ is a positive number in [1, e2a2] for every pair (r, s); divided by the lengths of the two terms, it is the cosine similarity shown in Figure 8. Every Δfr therefore has the sign of −ℓ′, the N loop contributions add instead of cancelling, and their sum is proportional to N·cN·N−γN.

Squeezed from both sides, only (1, 0) remains. Putting the three steps side by side:

1. Forward init‖𝒙N‖rms∼NcN∝N1−αN≤O(1)⟹αN≥1
2. Feature step‖Δ𝒉1‖rms∝N−γN≤O(1)⟹γN≥0
3. Output Δf|Δf|∼NcNN−γN∝N1−αN−γN=Θ(1)⟹αN+γN=1
Unique solutionαN=1−γN≤1andαN≥1⟹(αN,γN)=(1,0)

Steps 2 and 3 together give αN = 1 − γN ≤ 1 (the upper bound from training), while Step 1 gives αN ≥ 1 (the lower bound from the forward pass). The bounds coincide at the unique solution (αN, γN) = (1, 0). This directly answers our two opening questions:

  • Why does decaying faster (αN > 1, such as N−3/2) fail? If αN > 1 with an N-independent learning rate (γN = 0), the output change N1−αN vanishes as N grows and training stalls; if we try to compensate by growing the learning rate with N (γN = 1 − αN < 0), the first-loop feature change N−γN blows up.
  • Why doesn’t the learning rate need to be divided by N when the shared weights receive N gradients? Once each residual branch is scaled by cN = a/N (αN = 1), each loop’s gradient already carries a factor of 1/N, so the sum of N loop gradients is automatically an average whose magnitude does not grow with N; on the forward pass, the N aligned uses of the updated weight cancel the 1/N branch factor so the total output change stays Θ(1). Whether we use Adam (which normalizes gradients) or raw SGD, the learning rate stays independent of N (γN = 0).

Depth versus loops: why depth allows an interval while loops leave a single point. For L layers with independent weights, write the branch multiplier as cL = aL−αL and the learning-rate scaling as L−γL, and repeat the analysis (as in Depth-μP). Notably, the training side gives the exact same constraints: although each layer’s update ΔWl is used only once (in layer l), it still aligns with its input xl−1 and nudges the final output in the loss-reducing direction (−ℓ′) by cLL−γL; the L layers still add constructively in the output change, giving L·cL·L−γL ∝ L1−αL−γL. Thus independent layers also require γL ≥ 0 and αL + γL = 1, setting the upper bound αL ≤ 1. The only difference lies in the initialized forward pass.

Independent layers add like a random walk as √L on the forward pass, requiring only αL ≥ 1/2. That leaves the interval αL ∈ [1/2, 1] (with learning-rate exponent γL = 1 − αL), whose two endpoints are Depth-μP at (1/2, 1/2) and CompleteP at (1, 0). A shared block adds linearly as N on the forward pass, pushing the lower bound up to αN ≥ 1—right onto the training upper bound αN ≤ 1—and collapsing the interval to the single point (αN, γN) = (1, 0). Switching the weights in Figure 9 from shared to independent shows this change: the boundary of “unstable at init” retreats from α = 1 to 1/2, and the feasible choices grow from a single point into a segment of the diagonal.

The paper’s appendix extends this result to a full classification of all (αN, γN) over any finite training horizon, and to residual branches with several matrices, such as a multi-layer MLP block; the recipe for the attention blocks of a Transformer follows by analogy. The proofs cover linear networks trained with SGD; for nonlinear activations and Adam, we justify the result under additional assumptions.

One optimizer step in a real Transformer follows the same prediction. At initialization, we take one AdamW step with the same learning rate for every N (γN = 0) and measure the change of the final residual stream. Our derivation predicts a change proportional to N1−αN: independent of N only under αN = 1, growing with N for smaller αN, and shrinking for larger. The measurements agree: the change grows with N under αN = 0 and 1/2 and shrinks under αN = 3/2, whereas under αN = 1 the first-step change stays between 0.08 and 0.19 as N grows from 1 to 64. The Loop-μP recipe

A real looped Transformer combines depth L and loop count N: each loop runs a stack of L distinct layers with independent weights, and that entire L-layer stack is repeated N times with shared weights. Applying the conclusions of the previous section to each dimension:

  • Loop dimension N: repeating the stack N times adds constructively across loops, fixing the unique exponents αN = 1 and γN = 0—multiply each residual branch by N−1 and keep the learning rate free of N (multiply by N0).
  • Depth dimension L: within a single loop, the L independent layers add like a random walk as √L, allowing αL ∈ [1/2, 1] with γL = 1 − αL. As in Depth-μP, we ask the features of every layer within a loop to evolve as much as possible, which selects the left endpoint αL = 1/2, γL = 1/2—multiply both the residual branch and the hidden-layer learning rate by L−1/2.
  • Width dimension n: following standard μP, scale the hidden-layer Adam learning rate by n−1.

Combining all three dimensions gives the residual branch multiplier and hidden-layer Adam learning rate of Loop-μP:

c=a·N−1⏟loop (α_N = 1)·L−1/2⏟depth (α_L = 1/2),ηhidden∝η·n−1⏟width (μP)·L−1/2⏟depth (γ_L = 1/2)·N0⏟loop (γ_N = 0)

Written as a full recipe for pre-LN Transformers (with width multiplier mn = n/nbase and depth multiplier mL = L/Lbase relative to a base model), Loop-μP differs from the untied recipe in only one place: the attention and MLP residual branches are each multiplied by an extra 1/N. The initialization variances, learning rates, weight decay, and AdamW ε rules are identical to the untied recipe, so a model tuned at N = 1 can be looped more times simply by dividing its residual branches by N.

One learning rate for every loop count

We train Llama-style pre-norm looped Transformers on FineWeb-Edu for 10B tokens each. The token embedding and the output head stay outside the loop, and a stack of L layers (L = 12, 24, 48) is looped N times (N = 1, 2, 4, 8). For every (L, N), we sweep the learning rate around the base value tuned at L = 12, N = 1. At L = 12, we compare four loop factors: unscaled (1), N−1/2, which treats the loops as depth, N−1 (Loop-μP), and N−3/2, which decays faster than the theory prescribes. At L = 24 and 48 we use only Loop-μP and, as the theory predicts, multiply the learning rate by (L/12)−1/2.

Only N−1 keeps the best learning rate fixed across N. Under Loop-μP, the best base learning rate is 1.25×10−3 for every N at L = 12, and the same holds at L = 24 and 48. Under the other three loop factors, the optimum moves:

  • Without a loop factor, the best learning rate falls from 1.25×10−3 at N ≤ 2 to 7.5×10−4 at N = 8, and learning rates of 3×10−3 and above diverge at N ≥ 4. This matches a one-step change that grows with N.
  • Under N−3/2, the best learning rate rises from 1.25×10−3 at N = 1 to 3×10−3 at N = 8. The theory predicts this rise: the one-step response now shrinks as N−1/2, so making up for it takes a learning rate that grows as N1/2, about 3.5×10−3 at N = 8.
  • Under N−1/2, the best learning rate also moves at N ≥ 4.

Loop-μP also reaches the lowest loss. For every N > 1, its best loss is lower than under all three other loop factors, and it falls the most as N grows. This matches the forward pass, where the unscaled branch and N−1/2 let the residual stream grow with N, and N−3/2 drives the looped model toward the identity map.

With the depth factor applied, the same base learning rate is also best at L = 12, 24, and 48. In other words, one base learning rate is best for every (L, N) we train.

After training: loop increments stay aligned

The two predictions above were checked at initialization. Do they still hold after full training (20,000 steps)? For looped models with N = 8, we compute the cosine similarity between the increments of every pair of passes, and compare it with the per-layer increments of a trained untied model with L = 48.

The similarities between pass increments are lower than at initialization, but every pair of passes that excludes the final pass remains positively correlated, at all three depths; only the final pass is weakly or negatively correlated with the others. The layer increments of the untied model have low similarity overall and align mainly with nearby layers.

We also trace the residual-stream norm after every pass. The trajectories differ across N, but within each depth the norm after the last pass varies by at most a factor of 1.32, consistent with a norm that does not change with N at initialization.

Conclusion

What separates looping from adding depth is weight sharing. Shared weights make the increments that every loop writes into the residual stream, and the changes caused by one update, add along the same direction instead of spreading over unrelated directions as independent layers do. The resulting Loop-μP multiplies each residual branch by 1/N on top of an existing depth parameterization and keeps the learning rate independent of N. In our language-modeling experiments, Loop-μP transfers the learning rate across loop counts (up to 8) and executed depths (up to 384 layers), and reaches a lower loss than loop factors that decay more slowly or faster than 1/N.

This work has limitations. Following Depth-μP, our theory analyzes a mean-centered MLP residual block and proves its results for linear networks; the extension to nonlinear activations and Adam relies on additional assumptions, and attention and normalization layers are not yet part of the analysis. Limited by compute, our largest model has 438M parameters and is trained on 10B tokens, and we leave larger scales to future work.

We hope Loop-μP offers the looped-model community a simple recipe for training better looped models at a lower tuning cost.
